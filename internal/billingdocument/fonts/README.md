# Noto Sans TC for transaction-detail PDFs

The regular and bold TrueType files are static instances (weight 400 and 700) of Google's [Noto Sans TC variable font](https://github.com/google/fonts/blob/main/ofl/notosanstc/NotoSansTC%5Bwght%5D.ttf). The source font is distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt). The PDF renderer embeds only glyphs used in each document, so recipients can read Chinese names without a local CJK font or Adobe CMap package.

Source variable font SHA-256: `864727d210d54f2537bbe23b3a839436c3992af72de9322af5270897246bd44f`

Generated with fontTools 4.57.0 using `fontTools.varLib.instancer.instantiateVariableFont` at `wght=400` and `wght=700`, with all glyphs retained for customer names. SHA-256:

- `NotoSansTC-Regular.ttf`: `51ec08d53f6bb078d7cf356e0ae809c41264179e1d21d1ab3c1048bbb3a0d67c`
- `NotoSansTC-Bold.ttf`: `be93d4a8e606cd3f2476013cb2440098736f3beb07d0f1d10dedd06f51ea66c7`
